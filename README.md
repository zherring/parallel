# Parallel (coming soon)

Placeholder landing page for Parallel, a free, non-commercial site for exploring film
collaborations: line up the careers of any two people in film and see every movie they
made together. It will live at https://parallel.zachherring.com.

    npm install && npm start    # serves ./public on $PORT (default 3000)

This scaffold is temporary and will be replaced by the Next.js app (TMDB API).
Film data will come from TMDB; the page carries the required TMDB attribution notice.
